## Deploying to GitHub Pages

1. Push this folder's contents to a repository (keep `index.html` at the repo root).
2. In the repo: **Settings → Pages → Source: Deploy from a branch → main / (root)** → Save.
3. The contract goes live at `https://<username>.github.io/<repo>/`.

`index.html` is fully self-contained — logos, stylesheets, fonts, and scripts are
inlined, so nothing else needs to be hosted. Viewers need an internet connection
(React and Google Fonts load from CDNs).

## Notes

- This is a **review copy** — the signature page is intentionally disabled.
- "Request Changes" opens the viewer's email app pre-addressed to
  `team@thiinkmediagraphics.com`.
- To update the contract, edit the Rev. 2 SOURCE file in the TMG Live Contracts
  project, re-export the standalone, and replace `index.html`.
